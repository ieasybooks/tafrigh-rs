# tafrigh-transcribe

The native runtime used by tafrigh's Cohere backend. This package combines the pinned MIT-licensed transcribe.cpp source and Rust bindings, with a small set of Cohere CUDA patches maintained in tafrigh-rs. It is a downstream package, not an official transcribe.cpp release. The Rust library keeps the `transcribe_cpp` name so the existing recognizer uses the upstream API. This bundle is scoped to these Cohere fixes; return to the upstream crates when a suitable release includes them.

Normal Cargo builds verify the bundled source archive's SHA-256, extract it into `OUT_DIR`, apply the patches, and compile it through CMake. The build uses no network, does not modify Cargo's registry cache, and needs no `TRANSCRIBE_DIR` override or separate library installation. Source, bindings, licenses and patches are included in the published crate. CMake and a C++ compiler are required; CUDA builds also need the toolkit.

`TRANSCRIBE_DIR` is rejected: linking an external runtime would bypass the bundled patches. Unset it before building. `TRANSCRIBE_CMAKE_ARGS` remains available for toolkit architecture and other CMake settings.

`native/upstream.json` records the source release, commit, registry checksums, binding adaptations and patch targets. The archive is the unchanged crates.io `transcribe-cpp-sys` package. The Rust files are copied from the corresponding official safe and raw binding packages; local adaptations combine their module paths and derive the native ABI version from that metadata independently of tafrigh's package version. `native/build.rs` preserves the upstream build helper with an explicit source-directory argument, without its prebuilt override or watches on generated files.

The CUDA patches select explicit encoder attention because the bundled CUDA Flash Attention implementation does not support Cohere's 160-wide heads and per-head relative-position mask. They also make the GLU sigmoid input contiguous. Both changes prevent per-layer CPU fallback. Decoder Flash Attention and the upstream environment overrides remain available. Other model families keep their existing convolution policy.

The 0.4.0 → 0.4.1 native update also enables memory-mapped weights on supported CPU and Metal paths and moves Cohere's Q-bias fusion into a separate F32 buffer. Keep a mapped model file unchanged while it is in use; updating through a new file and atomic rename is safe. tafrigh's model downloader already uses that approach. Shared conformer changes in this upstream release do not change Cohere's CPU/CUDA graph policy.

To refresh or update the runtime, run `mise exec -- sh scripts/update-transcribe.sh VERSION` from the repository root, then review the source/metadata diff. The script downloads matching native and binding crates, checks their registry checksums, and reproduces the local binding/build adaptations. If a patch no longer applies, the script stops without changing managed files and removes its temporary source tree. Extract `transcribe-cpp-sys-VERSION.crate` separately outside the checkout, update the affected patches in `crates/tafrigh-transcribe/native/patches/` against that extracted source, then rerun the updater and review the generated diff. Run package verification, workspace checks, and real-model CPU/CUDA accuracy and throughput comparisons before submitting the update. Normal builds use the bundled archive without downloading native source.

This crate follows tafrigh's release version. Its bundled native ABI version is recorded in `native/upstream.json`. The first crates.io publication requires registering this package before enabling trusted publishing, as described in the repository's release guide.
